# Быстрый старт Telegram Keyword Monitor

## 🚀 За 5 минут до первого запуска

### 1. Подготовка (1 мин)

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd telegram-keyword-monitor

# Инициализация
make init
```

### 2. Настройка .env (2 мин)

Откройте `.env` файл и измените:

```bash
# 1. Задайте надежный пароль БД
POSTGRES_PASSWORD=your_secure_password_here

# 2. Сгенерируйте и вставьте SECRET_KEY
make secret-key
# Скопируйте вывод и вставьте в .env

# 3. (Опционально) Telegram бот для админских уведомлений
TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
ADMIN_TELEGRAM_CHAT_ID=123456789
```

### 3. Запуск (2 мин)

```bash
# Запустить всё
make up

# Подождать ~30 секунд для инициализации БД и миграций
```

### 4. Проверка работы

Откройте браузер:
- Frontend: http://localhost:8080
- API Docs: http://localhost:8000/docs

## 📱 Первый Telegram аккаунт

### Получение Telegram API credentials

1. Откройте https://my.telegram.org
2. Войдите с вашим номером телефона
3. Перейдите в **API development tools**
4. Создайте приложение (любое название)
5. Сохраните:
   - `api_id` (число, например: 12345678)
   - `api_hash` (строка, например: abcdef123456...)

### Добавление аккаунта через веб-интерфейс

1. Зарегистрируйтесь на http://localhost:8080
2. Нажмите **"Add Account"**
3. Заполните форму:

```
Phone Number: +1234567890
API ID: ваш_api_id
API Hash: ваш_api_hash

Monitored Channels: (по одному на строку)
@channelname
-1001234567890

Forward To: @yourbotchannel или -1001234567890

Whitelist Keywords: (опционально, по одному на строку)
bitcoin
crypto
trading

Blacklist Keywords: (опционально)
spam
scam

Text Replacements: (опционально)
BTC -> Bitcoin
ETH -> Ethereum
```

4. Нажмите **"Create Account"**
5. Введите код из Telegram
6. (Если есть 2FA) Введите пароль

✅ Готово! Аккаунт начнет мониторинг автоматически

## 📋 Типичные проблемы

### "FloodWait" ошибка
**Решение**: Подождите указанное время. Используйте прокси для разных аккаунтов.

### "Invalid code" при верификации
**Решение**: Проверьте правильность кода. Запросите новый код если истек.

### Сообщения не пересылаются
**Решение**: 
- Проверьте Channel ID (должен начинаться с `-100` для supergroups)
- Убедитесь что аккаунт имеет доступ к каналу
- Проверьте whitelist/blacklist настройки

### Backend не запускается
**Решение**:
```bash
# Проверьте логи
make logs-backend

# Проверьте что БД запущена
make test

# Пересоберите
make rebuild
```
